These durations are already included in wall time. They cover recorded RDS operations, including serialization, rather than pure disk I/O. The operating system cache was not cleared.

A1: 6 calls in each run. Request 1 inspects input, then combines validation, QC, aggregation and output writing. Request 2 combines paired analysis and plotting while reusing session objects. Request 3 combines analysis and outputs, writes the report, then performs a separate final check. None of the three runs required tool-error recovery.

C1-1: 13 calls, split 8 / 3 / 2. Request 3 already combined related operations. Request 2 failed to reuse an interactive R process from the preceding request: the process ID was no longer available. The agent recovered by starting a new Rscript process and reading the saved composition CSV. The original input was read again in Request 3.

C1-2: 11 calls, split 7 / 1 / 3. An existence check found R's built-in raw function instead of the intended data object. The agent corrected the check and reran the computation. It read input.rds once, but read a saved copy of the large matrix twice more. Counting only input.rds reads would overstate data reuse.

C1-3: 14 calls: 8 commands and 6 progress queries. Request 1 incorrectly rejected the stored matrix class through an identical comparison. The agent changed the class-membership check and reran the step. Request 3 reread the original matrix and queried progress three times.
