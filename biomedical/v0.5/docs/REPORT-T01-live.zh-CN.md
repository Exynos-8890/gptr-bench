A1 按 gptr 的实际工具派发计数。
C1 按原始会话中的内部工具调用计数。
外层 exec 包装不重复累加，进度查询也计入工具调用。

本轮 C1 多出的调用涉及环境探查、stdin 交互或轮询、错误恢复。
三次 C1 各有一次工具错误；A1 没有工具错误。
A1 三次仍各有一次独立收尾检查。

这不是 R 函数内部调用次数，也不是模型 API 请求次数。
C1 的一条 Shell 命令可以同时完成计算、画图和写报告。
因此，工具次数相同不代表工作量相同。
