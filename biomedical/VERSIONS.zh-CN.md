## C 历史证据与后续维护

| 项目 | 处理方式 |
|---|---|
| 原始数据与运行记录 | 保留原路径，避免冻结清单失效 |
| 旧方案与配置入口 | 使用相对符号链接，指向对应版本目录 |
| 已审核结果 | 移入版本目录，保留旧目录的兼容链接 |
| 科学方案版本 | 保留原版本；本次另记目录修订与UTC时间 |
| 中文文档与HTML | 继续由 `*.zh-CN.*` 规则排除在Git之外 |
| v0.5下一步 | 获准后进行AWS部署、资源试跑和正式采样 |
