# Benchmark v0.3 改进建议：加入大规模真实数据

现有 v0.2 的 `veteran` 是真实数据，但只有137行；十万行合成队列也仅约3.2 MB。下一版应补上大规模真实数据这一层，小数据继续用于流程检查。

参考 [BiomniBench](https://www.biorxiv.org/content/10.64898/2026.05.12.724604v1) 从已发表研究构造多步任务、检查分析过程的做法，建议直接采用其[第二版任务示例](https://www.biorxiv.org/content/10.64898/2026.05.12.724604v2.full)使用的 [GSE236581](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE236581)。该队列含22位患者、169份样本、975,275个细胞；公开表达矩阵压缩后约3.9 GB，附细胞、基因及患者／组织／治疗时点信息。原研究发表于 [Cancer Cell](https://www.cell.com/article/S1535610824002344/pdf)。这将新增单细胞任务，沿用五组比较框架。数据可从 GEO 直接获取，下载计数矩阵及配套标识、注释文件即可，无需先取得论文整套任务包。

任务依次为：读取计数矩阵并核对细胞标识、计算质控指标；筛选后按患者、组织和时点汇总表达；修改质控阈值，复用数据重算。三步均实际操作表达矩阵。检查器核对细胞数、汇总值和筛选过程。各组使用相同的输入、子集标识和产物要求，并保留中间操作记录，便于复核分析步骤。

先以固定真实细胞子集跑通五组，再在内存足够的机器上测全量。全量稀疏矩阵仅数值和索引估计约15.7 GB，解析峰值需预检；真实子集只筛选原有细胞，不复制扩增数据。保留真实组各三次、回放各十次，先验证轨迹正确再转换 fake provider。

统一固定GPT 6.1 SOL模型，记录数据校验值、下载日期、源码及软件版本。数据准备排除在计时外，加载和权限开销计入。拟新增 `tasks/single-cell.R`，结果放入 `reports/gse236581-v0.3/`；验收标准是五组产物正确、时间和内存记录完整。10万真实细胞实验已完成，结果见 [v0.3实验报告](RESULTS-v0.3.zh-CN.md)。
